# data

Generated by the pipeline, one folder per server in `servers.yaml`. Do not edit by hand.

Each `data/<server>/` holds `manifest.json`, `reagents.json`, `entities.json`, `recipes.json` and
`sources.json`. Their shape is defined in `pipeline/src/ss14help_pipeline/models.py`; see
`schema/examples/` for a small hand-written snapshot.
