How to use ss14help

ss14help is a tool to help find updated recipes and reactions from the game Space Station 14. You can search for recipes by category, or search for reactions by the ingredients they require. Note: All recipes are fetched from upstream WizDen repository.

Navigation

Explore different categories by using the tabs to navigate

Search

Type in to filter the list

Clicking on search suggestion will apply it to the search bar

Reaction Calculator

Just for reactions: type the amount (u) followed by the reaction id to get a rundown of the costs, recursively

Example: 30u RobustHarvest
